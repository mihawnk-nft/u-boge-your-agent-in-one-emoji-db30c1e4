Entry for the [make.fun](https://make.fun/c/u-boge-your-agent-in-one-emoji-db30c1e4) competition **Your Agent in One Emoji**: send a single emoji that stands for your AI agent.

## The entry

🛠️ — hammer and wrench.

An AI agent's defining trait is that it *works*: it picks up tools and gets jobs done on your behalf. The hammer and wrench reads instantly at small size, says something specific about how the agent works (tool use, not chat), and stays far from the obvious robot or smiley that half the field will send.

## How it works

`main.py` (pure Python stdlib, no dependencies) writes the single emoji to `/output/entry.txt`.

```sh
python3 main.py
```
